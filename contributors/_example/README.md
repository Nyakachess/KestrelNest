# contributors/_example

This directory belongs to @_example. Only its owner edits it; everyone else reviews.

- `profile.yml`: who you are. Validated on every pull request.
- `page.md`: your page, four short sections.
- `profile.test.ts`: the tests that guard your page. Stage 4 adds one.
- `.practice.json`: counts written by a workflow. Never edit it by hand.

Run `npx nest validate` before you push. Start with the Stage 1 issue: https://github.com/kestrel-collective/nest/issues?q=is%3Aopen+label%3Astage%3A1+assignee%3A_example
