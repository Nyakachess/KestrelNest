# contributors/anod-a

This directory belongs to @anod-a. Only its owner edits it; everyone else reviews.

What is here and what to do with it:

- `profile.yml`: who you are. Fill it in during Stage 2. Checked on every pull request.
- `page.md`: your page, four short sections. Fill in "Where I started" during Stage 2.
- `profile.test.ts`: the tests that guard your page. Stage 4 adds one.
- `.practice.json`: counts written by a workflow after your pull requests merge. Never edit it by hand.

Before you push: `npm run validate` tells you the file, the line and the field of anything that needs changing. To see your page, run `npm run dev` and open http://localhost:4321/p/anod-a/ (once it is public).

Your issues, in order: https://github.com/kestrel-collective/nest/issues?q=is%3Aopen+assignee%3Aanod-a+label%3Aonboarding
