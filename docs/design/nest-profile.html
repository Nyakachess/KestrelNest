Where I started

My first PR added one line to CONTRIBUTORS.md and failed CI twice: once for a trailing space, once because I had not run the formatter. Fixing those two things taught me more about how real projects work than any tutorial had.

Kestrel Nest #412 ↗

What I learned

Reproduce before you touch anything. On my Stage 3 defect I spent twenty minutes reading the renderer before I had even seen the bug happen. Writing the hypothesis down first, as the guide asked, felt slow and then found the cause in one check.

What I built

This page, the test that guards its dates, and a Skills section renderer for every page on Nest (my Stage 5 contribution, in release v1.4).

What I am working on next

Automated testing at the supported level: designing a test without a pattern to copy, and saying in the PR why it guards the defect.
