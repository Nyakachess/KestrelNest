# Governance

Nest is maintained by Kestrel Collective. It is small on purpose, so the rules are short.

## Roles

- Contributor: anyone with a directory, or anyone who opens a pull request. Owns their own directory.
- Cohort lead: a maintainer who opens a cohort, reviews its scaffold pull requests and keeps the stage issues moving.
- Maintainer: a member of the `maintainers` team. Reviews shared-code changes, merges, releases, and decides on proposals. Listed in CODEOWNERS.

## How decisions are made

- Small changes: a pull request and one maintainer review.
- Changes to how the project works: an architecture decision record under `docs/adr/`, under 25 lines, accepted by two maintainers. Stage 7 proposals start as an issue and end as a record or a pull request.
- Disagreements are settled by the maintainers, in the open, in the pull request or issue where they started.

## Releases

Quarterly, or when a cohort ends. Semantic versioning. Every release has a changelog entry that credits contributors by handle.

## Changing this document

Through a pull request, like everything else.
