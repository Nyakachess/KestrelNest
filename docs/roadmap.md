# Roadmap

What Nest is, release by release. Dates are intentions, not promises.

## v0.1.0: the ladder exists (this release)

- One directory per contributor with validation that explains itself.
- The `nest` command: validate, scaffold, new-task, feed, open-cohort.
- The site: home, contributor pages, cohort pages, the pages feed.
- Seven stage issue bodies and the first cohort can be opened with one command.
- Counts from merged pull requests, written by a workflow.

## v0.2: the first cohort runs

- Open the first cohort and fix what the first twenty pull requests reveal.
- Preview deploys on every pull request.
- Cohort metrics that come from GitHub: first PR merged, median days to it, shared-code PRs.
- The Stage 5 backlog grows from real gaps, labelled `good-shared-issue`.

## v0.3: evidence from Kestrel records

- Verified external contributions replace owner-listed ones where Kestrel records exist, with a verify link.
- Competency levels on the profile aside, from the same records.
- "Then and now": a snapshot of every published page at the end of each cohort.

## Later

- Archive pages per cohort snapshot at `/archive/<cohort>/`.
- A page for maintainers that lists stale scaffolds and open stage issues.

Propose a change to this file through a pull request. That is Stage 7.
